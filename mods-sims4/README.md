# Pacotes Sims 4 recebidos

Esta pasta preserva os arquivos `.package` originais enviados para o projeto.

## VHSync — Dunk High Men's Sneakers
- Convertido para o catálogo do Meu Lar como **Tênis Dunk High**.
- Público: corpo masculino adulto do Sims 4 (`am5`).
- Categoria no criador: **Sapatos**.
- Cores: 38 swatches do package.
- Os arquivos convertidos ficam em `app/src/main/assets/cute/skate/`.

## MizoreYukii — StandStillInCAS All-in-One
- Mantido aqui sem alterações.
- O package contém um único recurso XML de ASM/estado de animação do CAS (`0x02D5DF13`, `ASM name="CAS"`); não contém malha 3D nem textura.
- O Meu Lar não executa tuning ASM do The Sims 4. Por isso, esse arquivo não foi inserido no catálogo 3D nem tratado como peça de roupa.
- Para usar esse mod no The Sims 4, copie o `.package` original para a pasta `Mods` do jogo, conforme as instruções do criador do mod.
